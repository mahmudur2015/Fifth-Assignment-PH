Question-1: What are the different ways to select an element in the DOM?

There are 5 ways in which we can select elements in a DOM using selctors.

a. getElementsByTagName()

b. getElementsByClassName()

c. getElementById()

d. querySelector()

e. querySelectorAll()

Question-2: What is the difference between innerHTML, innerText, and textContent ?

a. innerHTML is used when we want to insert or retrieve HTML markup

b. innerText is used when you want only the rendered visible text as seen by the user

c. textContentwhen we want the full text, regardless of CSS visibility

Question-3: What is event delegation in the DOM?

Event delegation is a technique in JavaScript where a parent element handles events for its child elements, even if the children are added dynamically after the page loads

Question-4: What is event bubbling in the DOM?

Event Bubbling is a concept in the DOM.It happens when an element receives an event, and that event bubbles up to its parent.

Event fires on the child first,then bubbles up to the parent.

Question-5: How do you create, add, and remove elements using JavaScript?

To add, remove, and modify HTML elements using JavaScript, we can use methods like createElement(), appendChild() or append(), removeChild() or remove() , and properties like innerHTML and textContent. For example, to add an element, we can create it using document.createElement and then append it to a parent element using appendChild().
